# 第18篇公开复核包：观测延迟的配对评估

解压后，在README所在目录，用已有兼容Python环境执行：

```text
python -B evaluate.py --output-dir result-r001
```

输出目录必须不存在。默认只读CPU离线复算，不创建仿真环境、不reset/step、不采集、训练、拟合或搜索参数。已实际验证Python3.11.9、NumPy2.4.6和Pillow13.0.0，无需升级研究依赖。图表已提供，不要求安装渲染或训练依赖。

包含10条完整真实数值轨迹、210张原始PNG及8份实际反馈审计：两个seed各U、C0、P0、C1、P1。U为第13篇脚本，C0为第16篇即时无干预反馈，P0为第15篇即时有干预反馈；C1/P1为本篇四条新增运行。旧来源保持原始数值与审计字段。

外层只延迟第一关节测量一个控制周期0.05秒，参考及前馈时钟不变；底层PD仍使用当前状态。gain=1，原float32限幅不变，首次动作9用状态8，动作10用状态9，动作19用状态18。前缀不是反馈查询，没有伪造NaN审计。

evaluate.py检查files.json的SHA，独立核对N/N+1、时间、动作、PNG像素、原回合标志、参考/测量索引、全部反馈公式、clip/touch、当前锚点与配对指标。与本包根目录metrics.json及两个comparison.npz对应。来自作者的validation.json同时报告私人账本/旧文件保护已通过；公开评估不会访问私人工作区。

参考公式副本feedback_controller.py与第15篇字节相同；delayed_feedback.py说明实际缓存语义。公开evaluate.py不调用采集或反馈决策函数，使用独立索引和算式复核。provenance.json记录适配源码哈希，默认包不含任何采集入口或维护工具。

C1无干预也偏离参考，故同时计算r0=P0-C0、r1=P1-C1及r1-r0，不能把P1相对U的变化全归因于干预。两seed均已使用，各组1秒、success=false；不作随机化因果、普遍稳定、恢复能力、推物或真实机器人时延结论。

schema.json列出完整字段与单位；指标精度、全部逐步CSV/数组和原尺寸图均保留。原始日志、私人机器信息、设备原始枚举、私有人工夹具和维护工具不公开。此包只验证现有保存结果，不执行新的仿真。
