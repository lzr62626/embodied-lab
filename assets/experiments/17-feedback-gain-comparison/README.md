# 第17篇公开复现包：固定增益对照

解压后，在本文件所在目录用已有兼容Python环境执行：

```text
python -B evaluate.py --output-dir result-r001
```

输出目录必须不存在。只进行CPU离线验收，不创建环境、不reset/step、不训练、拟合或选增益。已验证Python3.11、NumPy2.4.6、Pillow13.0.0，不要求升级研究依赖。

包含10份完整数值轨迹与210张原始PNG：两个seed各参考U、G0、G05、G1、G2。6份历史复用含参考，4份新增。G0实际为历史脚本续写，只验证gain0动作等价，没有实际反馈查询，也没有虚构feedback_audit.npz。

程序检查files.json中的SHA-256，读取allow_pickle=False数值资料，核对N/N+1、时间、动作、PNG像素及G05/G1/G2真实审计，并重新计算四档指标和逐步数据。输出metrics.json与本包根目录文件一致，comparison NPZ数组逐项相同。默认不包含任何采集入口。

provenance.json记录源码来源哈希与公开适配：移除私人采集账本/本机文件库存检查，保留数值检查。私人80次尝试账本与3216个旧文件保护已在作者项目核对，不在公开包中重新访问。

全部success=false。两个seed已使用，参考轨迹与时钟已知，每组1秒，没有新增增益的无干预条件，不选择最佳增益、不证明普遍稳定或推物能力。原始日志、设备枚举、人工夹具和维护工具不包含在包内。
